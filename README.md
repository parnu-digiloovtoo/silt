# Silt

Kolmeliikmelise 8. klassi tiimi digiloovtöö: tunniplaani järgi uueneva digitaalse uksesildi prototüüp Pärnu Hariduskeskuse ühele IT-õppeklassile.

## Eesmärk

Loome ekraanil töötava prototüübi, mis näitab ruumi infot, kuupäeva ja kellaaega, käimasoleva tunni õpperühma ning õpetajat ja päevast tunniplaani. Kuva muutub automaatselt kellaaja järgi. Seinale paigaldamine jääb edaspidiseks.

## Alustamine

1. Lugege [projekti kirjeldust](docs/Projekti-kirjeldus.md).
2. Tutvuge [eesmärkide ja nõuetega](docs/Eesmargid-ja-nouded.md).
3. Leppige kokku tööjaotus ja valige tahvlilt esimene ülesanne.
4. Kirjutage iga töökorra järel [tööpäevikusse](docs/Toopaevik.md).

Dokumentatsiooni sisukord: [docs/Home.md](docs/Home.md). Projekti juhendid on avaldatud ka [GitHub Wikis](https://github.com/parnu-digiloovtoo/silt/wiki).

## Kaustad

- `docs/` – projekti kirjeldus ja töökorraldus.
- `src/` – õpilaste loodava lahenduse kood.
- `data/` – näidistunniplaan.
- `design/` – ekraanivisandid ja kujundusotsused.
- `tests/` – katsete kirjeldused ja tulemused.
- `.github/` – ülesannete ja muudatusettepanekute mallid.
